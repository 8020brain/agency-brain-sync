Step 2 · Connect GitHub

Let's create your agency brain.

Your brain lives in a private repository on your business's GitHub organisation, so it stays yours and survives staff changes. A personal account won't work here: GitHub only lets apps create repositories inside an organisation.

1

Create the organisation

Every brain needs its own GitHub organisation. Create a free one now, then come back here.

The Free plan is all this needs, never pay; the paid plans add nothing here. Name it after the business. If GitHub asks who the organisation belongs to, "My personal account" is fine. On the "Start collaborating" screen, click "Skip this step". About a minute all up. Already made one? Go straight to step 2. Want GitHub's own step-by-step first? Read their guide.
